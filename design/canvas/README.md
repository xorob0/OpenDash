# Design canvas

Source files for the openDash design system canvas, a Claude Design artifact that can be
viewed and edited at
https://claude.ai/code/artifact/d3bca72c-f1ce-47f7-86a8-d2908add23d2

Each `*.dc.html` file is one artboard on the canvas, and `canvas.json` places them on three
pages. The values in these files are copied from [`../tokens.json`](../tokens.json) and follow
the reasoning in [`../../docs/design/brand.md`](../../docs/design/brand.md); when a token
changes, the artboard that shows it has to change with it, since nothing here is generated by
the build.

**The canvas is upstream of this directory.** It is edited online, these are copies, and when the
two disagree it is the canvas that is current. Refresh from it before making a change here. That
had not happened between 2026-09-10 and 2026-09-11, and in that gap the canvas went from tokens
0.3.0 to 0.9.2 and replaced the slot model with the zone model; twenty-two of twenty-four
artboards had drifted and `ZoneCatalogue.dc.html` did not exist here at all.

The artboards reference `./support.js`, which is part of the canvas runtime and is not in this
repository. These files therefore do not render standalone in a browser; they are here to be
read and diffed, and the canvas is where they are looked at.

## The model

The face is **zones**. A rectangular face is five parts: the rev bar in a recessed well, a bar of
settled values, a body of zone B, zone A and zone C, and band D across the foot. Each zone shows
one page at a time from its own catalogue and is cycled by a wheel button. A page is laid out for
the *shape* of its zone rather than its width, and sheds its secondary ranks before it shrinks its
numerals.

The slot model this replaced is recorded in [`../../docs/design/zones.md`](../../docs/design/zones.md)
and in ADR 0006. `CardsPostMvp.dc.html` still draws cards and is kept as the record of the pass
the zone model superseded.

## The layers

Colour goes palette, semantic, purpose. The parts go element, component, page, zone, layout: a
page is the changeable thing a zone shows, and a layout is a screen size that fixes the five
parts' rectangles.

| Page | File | Artboard |
|---|---|---|
| System | `Main.dc.html` | Foundations: layers, palette, semantic and purpose tokens, type, the numbered rules, the telltales, the token changelog |
| System | `DashComponents.dc.html` | Elements, components (one per flag), zone anatomy, states |
| System | `ZoneCatalogue.dc.html` | **The zone model.** The anatomy, the bar's eleven end fields, zone A's four pages, all twenty-one pages of zones B and C at four shapes each, and band D |
| System | `CardsPostMvp.dc.html` | Superseded. The eighteen further cards the slot model would have grown |
| System | `PagesAndAlerts.dc.html` | Flag formats, full-screen flag, pop-ups, idle and pit screens, the alert catalogue in priority order, change notifications, lap review |
| System | `Panels.dc.html` | Second-screen widgets: table row, relative, trace |
| System | `PluginComponents.dc.html`, `Plugin.dc.html` | Plugin controls and the settings panel: four zones, the bar, the buttons and the quick glance |
| DDU sizes | `Dash.dc.html` | 1920 × 480, the reference face |
| DDU sizes | `Dash1280x480`, `Dash1280x400`, `Dash850x480`, `Dash1280x720`, `DashNano800x286`, `DashDisplayDash600x686` | The other rectangular faces, each with its own zone rectangles |
| DDU sizes | `DashRound480`, `DashRound800` | The two round faces. **Still drawn on the slot model**; what a round face does with zones is XOR-94 |
| Second screens | `Companion850x480`, `Companion480x850` | A companion for a wheel or a phone: one module at a time behind a header |
| Second screens | `CompanionModules.dc.html` | The twenty-one modules, which also serve the zones and the pit wall |
| Second screens | `PitWall1920x1080`, `PitWallTower1920x1080`, `PitWallTelemetry1920x1080`, `PitWall1080x1920` | The three pit wall pages on a monitor, and the portrait variant |
| Second screens | `PitWallZones.dc.html` | The eleven standard and six wide data zone pages |

The dash artboards carry levers above the frame (lit segments, flag, pit limiter) so that the
state rules can be exercised on the canvas.
