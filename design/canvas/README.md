# Design canvas

Source files for the openDash design system canvas, a Claude Design artifact that can be
viewed and edited at
https://claude.ai/code/artifact/d3bca72c-f1ce-47f7-86a8-d2908add23d2

Each `*.dc.html` file is one artboard on the canvas, and `canvas.json` places them on three
pages. The values in these files are copied from [`../tokens.json`](../tokens.json) and follow
the reasoning in [`../../docs/design/brand.md`](../../docs/design/brand.md); when a token
changes, the artboard that shows it has to change with it, since nothing here is generated by
the build.

The system is layered, and so is the canvas. Colour goes palette, semantic, purpose; the parts
go element, component, card, layout. A card is the changeable module the plugin drops into a
slot, and a layout is a screen size that fixes the hero and declares its slot count.

| Page | File | Artboard |
|---|---|---|
| System | `Main.dc.html` | Foundations: layers, palette, semantic and purpose tokens, type, rules |
| System | `DashComponents.dc.html` | Elements, components (one per flag), the hero module, the twelve MVP cards at three rungs, states, slot map |
| System | `CardsPostMvp.dc.html` | Eighteen further cards: relative, leaderboard, map, radar, sectors, fuel calculator and so on |
| System | `PagesAndAlerts.dc.html` | Flag formats, full-screen flag, pop-ups, idle and pit screens, the alert catalogue in priority order, change notifications, lap review |
| System | `Panels.dc.html` | Second-screen widgets: table row, relative, trace |
| System | `PluginComponents.dc.html`, `Plugin.dc.html` | Plugin controls and the four-section settings panel |
| DDU sizes | `Dash.dc.html` | 1920 × 480, the MVP, twelve slots |
| DDU sizes | `Dash1280x480`, `Dash1280x400`, `Dash850x480`, `Dash1280x720`, `DashNano800x286`, `DashDisplayDash600x686`, `DashRound480`, `DashRound800` | The other DDU sizes from `screen.future`, each with its own slot count |
| Second screens | `Companion850x480`, `Companion480x850` | A companion for a wheel or a phone: one module at a time behind a header |
| Second screens | `CompanionModules.dc.html` | The twenty-one companion modules, which also serve the pit wall zones |
| Second screens | `PitWall1920x1080`, `PitWallTower1920x1080`, `PitWallTelemetry1920x1080`, `PitWall1080x1920` | The three pit wall pages on a monitor, and the portrait variant |
| Second screens | `PitWallZones.dc.html` | The eleven standard and six wide data zone pages |

The dash artboards carry three levers above the frame (lit segments, flag, pit limiter) so
that the state rules can be exercised on the canvas. Edits made in the canvas editor do not
flow back into these files; when the canvas has been edited online, it is the canvas that is
current, and these files should be refreshed from it before further changes are made here.
